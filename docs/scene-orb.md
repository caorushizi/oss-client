# 发光球壳：视觉与运动约定

目标是让原图中不规则、左侧破开的薄网球壳动起来，优先保证实际观感：丝线细腻、光晕柔和、层次清透，运动有方向且克制。风从右向左掠过，少量真实节点从左侧脱离，主体始终保持球壳形态。

参考图：[`apps/desktop/src/assets/images/global.png`](../apps/desktop/src/assets/images/global.png)。

## 必须保留的视觉特征

- 右侧具有清晰的球面弧度，左侧保留不规则破口和松散残边。
- 正面能看见较薄的网格；侧壁更细密，曲率和疏密共同表现球壳。
- 保留原图细丝重叠、主要网孔、交汇关系与不规则分布，避免均匀三角网或粗硬的多边形线框。
- 中心不能成为填满粒子的实心团，也不能被掏空成只有亮边的圆环。
- 所有节点之间都是独立直线，连线细、交点有亮芯和柔和光晕；整体亮度适合作为页面背景。

## 必须满足的运动行为

- 主体半径稳定，节点沿球面小幅错动；相邻节点的距离和连线角度真实变化。连线只由这两个端点决定，长度可以变化，中间始终不弯曲。
- 相邻节点共同响应从右向左的风，位移幅度与局部网孔大小匹配。
- 左侧离开的亮点来自原有球壳交点：源位置逐渐消隐，同一节点向左飘散并淡出。
- 同一节点 ID 和位置数据贯穿整个过程，原位置不保留发光副本。
- 循环复用只在节点不可见时重置位置，再从球面淡入；不能出现飞回球体的轨迹。
- 不允许整体呼吸伸缩，也不让连续的起伏波纹破坏球形。光流与球面的局部位移共同构成动态。

## 视觉实现方向

可见连线使用两个实时节点之间的直线段绘制，细线与柔光共用同一个笔直的轴线。球面运动只作用于端点，不对连线中间的位置施加非线性形变，因此整个动画中连线可以改变长度和角度，但不会弯曲。节点仍沿球面微动，球壳的轮廓与主体尺度稳定。

原图只用于开发预览中的静态对照，以及离线采样节点与直线。正式页面不加载这张图片，也不使用图片兜底或全屏纹理绘制。光晕直接来自直线与节点的着色器。节点离开时，其关联直线逐渐隐去，节点自身保持连续向左的轨迹。

## 运行对照预览

正式应用中的球体属于各自的页面滑动层：旧球体随旧页面滑出，新球体以新页面自己的固定位置随页面滑入，不在两页的位置之间插值移动。球体内部的节点动画仍然保留；离场期间停在最后一帧，切换完成后释放画布与 WebGL 资源，连续快速切页也只让当前页面持续播放。此效果在主应用 `/` 中验收，独立预览不包含页面切换。

在仓库根目录运行 `pnpm dev:web`，打开 <http://localhost:7789/orb-preview.html>。

- 默认播放动态效果；两侧使用相同背景、尺寸与位置。“静态对照”暂停并回到时间 0。
- “并排对照”便于同时比较；“放大查看”用于检查细网和交点。
- “播放 / 暂停”检查实际运动，“0.25× 慢放”观察节点离开与源位置消隐的过程。
- 开关“右 → 左的风”，分别检查壳面错动与节点剥离。
- 勾选“跟踪节点”，选择“左侧节点 1”；它从 3 秒开始脱离。
- 拖动时间滑杆或用方向键微调时间会暂停播放；“时间归零”便于复查同一过程。
- 系统开启“减少动态效果”时保留静态预览。

## 验收顺序

1. **先看整体：** 直接播放，在应用实际尺寸下检查球形、细丝层次、光晕和动感是否协调；不能用技术指标代替好看的画面。
2. **再看细节：** 切换静态对照，检查右侧弧度、正面薄网、左侧破口和疏密；关闭风并播放，确认局部运动没有变成整体伸缩，长短连线在多个时间点都保持笔直。
3. **再剥离：** 开启风，跟踪首个节点，在 3 秒前后慢放，确认它从现有网格离开，原位置同步消隐，没有发光副本。
4. **最后整页：** 在应用实际尺寸下检查亮度、层次与内容可读性，并检查缩放、暂停及持续播放。

节点都位于单位球面、节点数量合适、图像统计接近或构建通过，都不能单独证明“像原图”。必须直接比较可见网格、网孔与不规则轮廓；不得用减少中心节点数量代替视觉验收。

## 实现边界

- `apps/desktop/src/assets/images/global.png`：保留原图细丝、交点与柔和透明层次，仅用于开发对照与离线几何取样，不进入正式页面的资源包。
- `scene-orb-geometry.ts`：从参考图提取交点、连接及亮度依据，辅助定位和节点运动。
- `scene-orb-data.json`：保存最初的原图交点候选，供离线直线采样使用。
- `scene-orb-straight.json` / `scene-orb-data.ts`：保存并读取经原图沿线采样验证的直线与真实节点，页面启动不执行图像分析；坐标精度为原图的 1/32 像素。
- `scene-orb-boundary.ts`：只计算需要离开的边界节点，并按不可变节点图缓存结果，避免初始化整套旧模拟。
- `scene-orb-surface.ts`：提供交点与直线端点共用的切向位移场，以及真实节点离开、原位消隐和隐藏归位的状态。
- `scene-orb-shaders.ts`：在投影后的两个端点之间绘制直线与同轴光晕，控制细线光流与交点亮芯。
- `scene-orb-renderer.ts`：组织绘制、尺寸与投影、播放和定位、可见性及资源生命周期。
- `orb-preview.html` / `src/orb-preview.ts`：独立对照入口，不向生产页面加入调试控制。

完成修改后运行 `pnpm check:frontend`、`pnpm lint`、`pnpm build:web`，并按以上顺序进行视觉验收。

修改原图或提取算法后，依次运行 `node scripts/generate-orb-graph.mjs` 和 `node scripts/generate-orb-straight.mjs` 更新候选点与直线数据；`node scripts/generate-orb-straight.mjs --check` 检查直线数据是否与当前源图和算法一致。

## 性能约定

- 正常播放跟随浏览器刷新回调，不用丢弃时间余量的 30 FPS 节流。暂停、页面隐藏或球体离屏时停止持续绘制；减少动态效果时保留静态图形。
- 保留全部 5,726 条直线，使用两个绘制调用完成连线与节点。光晕采用解析透明度，不额外启用多重采样、深度缓冲或全屏图片绘制。
- 细线光照在顶点阶段计算端点与中点，再沿线插值；避免在数百万个光晕像素上重复计算三角函数。
- `data-ready` 仅在状态改变时写入，避免每帧引发样式失效；边界节点只计算一次并复用。
- 本机浏览器在相同 865 × 645 CSS 像素、相同像素比下，预热 2 秒后采样 10 秒：优化前约 29.4 FPS，优化后约 60.0 FPS；帧间隔 P95 从 34.6 ms 降至 17.6 ms。此结果是本机验证，不代表所有设备的帧率保证。
